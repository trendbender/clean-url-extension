# Store listing descriptions

The long description of each Chrome Web Store language, as pasted into Developer Dashboard → Store listing → Description. The dashboard is the only place they are published; these files are the source to copy from.

Rule (rejection "Keyword Spam / Yellow Argon", 2026-11-03): no lists of audiences, roles, brands or platforms ("Perfect for: marketers, SEO specialists, developers…"). Describe what the extension does, not who might search for it.
